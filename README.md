# PLC_price_OPTA — управление реле по цене электроэнергии

Прошивка для **Arduino Opta WiFi**. Устройство включает и выключает нагрузку
(например, электрический бойлер или обогрев) в зависимости от биржевой цены
электроэнергии **Nord Pool, зона Латвия (LV)**. Цены берутся из открытого API
[Elering](https://dashboard.elering.ee).

## Возможности

- 4 независимых реле (D0–D3), у каждого свои настройки.
- Новая цена каждые 15 минут, прогноз на сегодня и завтра.
- Сценарии для каждого реле (подробно — [docs/SCENARIOS.md](docs/SCENARIOS.md)):
  - **аварийный предел** — выше этой цены реле всегда выключено;
  - **порог включения** — ниже этой цены реле всегда включено;
  - **умный порог** — N самых дешевых часов за сутки;
  - **включение перед пробуждением** — N часов до заданного времени;
  - **включение ночью** — N самых дешевых часов в ночном окне;
  - **отпуск** — нагрев выключен до возвращения, кроме N дешевых часов перед ним;
  - **непрерывный нагрев** — кнопка на веб-странице включает реле на заданное время,
    не глядя на цену (аварийное включение по сети). *Пока в разработке, см. ниже.*
- Веб-страница настроек с графиком цены и плана работы: `http://opta-settings.local`.
- Работа по Wi-Fi. Ethernet служит для доступа к странице настроек.
- Точка доступа `Opta-Config-AP` для первой настройки Wi-Fi.
- Ручное управление: кнопка USER на корпусе и команды в Serial-мониторе.
- Защита: если новой цены нет больше часа, автоматические реле выключаются.
  Аппаратный watchdog перезагружает зависшее устройство.

## Быстрый старт

1. Установить [VS Code](https://code.visualstudio.com) и расширение **PlatformIO IDE**.
2. Открыть папку проекта, подключить Opta по USB-C.
3. Собрать и прошить: `pio run -e opta -t upload`.
4. Открыть монитор порта: `pio device monitor -b 115200`.
5. При первом запуске Opta поднимает Wi-Fi-сеть **Opta-Config-AP** (пароль `opta1234`).
   Подключиться к ней, открыть `http://192.168.4.1`, ввести SSID и пароль домашней сети,
   нажать «Сохранить настройки». Устройство перезагрузится и подключится к сети.
6. Дальше страница настроек доступна по адресу `http://opta-settings.local`
   или по IP-адресу из Serial-монитора.

Подробности, кнопка, светодиоды и диагностика — [docs/OPERATIONS.md](docs/OPERATIONS.md).
